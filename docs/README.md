# ModemBridge docs

This folder contains project-level documentation and planning notes.

ModemBridge is designed to be extended with new modem drivers over time (not limited to one vendor or model).
For integration details, see `../DRIVER_GUIDE.md`.

- `goal.md`: long-form product and architecture target for ModemBridge.
- `zte-goform-lab-report.md`: practical report for the first tested ZTE Goform protocol path.
- `protocol-lab-template.md`: reusable template for future modem/protocol bring-up reports.

Main package documentation remains in `../README.md`.
